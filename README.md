# 🎮 Tic-Tac-Toe Web Application

A modern and responsive Tic-Tac-Toe web application built using **HTML5, CSS3, and JavaScript**. The project features a clean glassmorphism-inspired interface, multiple game modes, strategic computer gameplay, winner detection, draw detection, and a visual winning-line indicator.

---

## 📌 Project Overview

This project was developed as part of the **SkillCraft Technology Web Development Internship – Task 3**.

The application provides two different ways to play:

- **Player vs Player** – Two players can play against each other on the same device.
- **Player vs Computer** – A player can compete against a computer opponent with strategic move selection.

The game automatically handles player turns, checks for winning combinations, detects draws, highlights the winning combination, and manages the transition between **Reset Game** and **New Game** options.

The interface was designed with a modern **dark glassmorphism theme**, combined with glossy X and O symbols, gradient buttons, responsive layouts, and smooth interactions.

## 🎮 Game Modes

### 👥 Player vs Player

Two players can play against each other on the same device.

- Player **O** starts the game.
- Players take turns placing their symbols.
- The first player to complete a winning combination wins.
- If all nine cells are filled without a winner, the game ends in a draw.

### 🤖 Player vs Computer

Play against a computer-controlled opponent.

- Player plays as **O**.
- Computer plays as **X**.
- The computer automatically makes its move after the player's turn.
- The computer checks for possible winning and blocking moves before selecting a move.

---

## 🧠 Computer Gameplay

The computer opponent uses a basic strategic decision-making system.

The computer follows this priority:

1. **Win** – Checks whether it can complete a winning combination.
2. **Block** – Checks whether the player can win on the next move and blocks it.
3. **Center** – Takes the center cell if it is available.
4. **Random Move** – Selects an available cell when no strategic move is required.

This provides a more engaging computer opponent than simply selecting completely random positions.

## 🎯 Game Rules

| Rule | Description |
|------|-------------|
| First Player | Player **O** starts the game |
| Turns | Players take turns placing **O** and **X** |
| Winning Condition | Get three identical symbols horizontally, vertically, or diagonally |
| Draw Condition | All nine cells are filled without a winner |
| Winning Indicator | A green line highlights the winning combination |
| Reset Game | Clears the current board and starts a fresh round |
| New Game | Appears after a win or draw |
